# Lisensi Aset Lingkungan Bali — CC0 1.0

Seluruh berkas PNG di folder `Assets/_Project/Art/Environment/`:

- `Gapura_CandiBentar.png`
- `Gapura_Menu.png`
- `PohonBeringin_Besar.png`
- `PohonBeringin_Kecil.png`
- `PuraMeru.png`
- `BaleKulkul.png`
- `Pelinggih.png`
- `Penjor.png`

dibuat khusus untuk proyek **Lentera Dirah: Lontar Mpu Bharada** melalui generator
`Game/Tools/generate_balinese_assets.py` (Python standard library, tanpa aset pihak ketiga).

Aset-aset tersebut dilepas ke **domain publik** di bawah
**Creative Commons Zero v1.0 Universal (CC0 1.0)** —
<https://creativecommons.org/publicdomain/zero/1.0/>.

Anda bebas menyalin, memodifikasi, mendistribusikan, dan menggunakan aset ini untuk
keperluan pribadi maupun komersial tanpa perlu mencantumkan atribusi.

Catatan budaya: bentuk gapura/candi bentar, meru bertingkat, bale kulkul, pelinggih,
penjor, dan pohon beringin digambar sebagai representasi sederhana arsitektur Bali
untuk keperluan prototipe akademik, bukan replika arsitektural yang presisi.
