# Lisensi BGM — Gamelan Gender Wayang

**Berkas:** `bgm_gamelan_girah.ogg`

| Atribut | Keterangan |
|---|---|
| Judul rekaman | *Gendér Wayang* (1928) |
| Ensambel | Gamelan Gender Wayang, Bali |
| Sumber | Wikimedia Commons — <https://commons.wikimedia.org/wiki/File:Gend%C3%A9r_Wayang_(1928).ogg> |
| Lisensi | **Public Domain** (rekaman historis 1928; lihat halaman berkas untuk keterangan rinci) |
| Format | Ogg Vorbis, stereo 44.1 kHz, 182 detik, ~3 MB |
| Tanggal unduh | 13 November 2026 |
| Penggunaan | Musik latar (looping) pada `AudioManager` — volume default 0.35 |

Rekaman ini dipilih karena sesuai GDD §5.3 (Gamelan Gender Wayang) dan berstatus domain publik,
sehingga aman digunakan baik di dalam game maupun pada video demonstrasi.

Catatan: karena rekaman berasal dari 1928, terdapat noise permukaan khas rekaman historis.
Nuansa tersebut justru memperkuat atmosfer malam Desa Girah.
