BAB I
RINGKASAN EKSEKUTIF (GAME OVERVIEW)

1.1 Identitas dan Spesifikasi Umum Permainan

Parameter Dokumen Spesifikasi Prototipe
Judul Permainan Lentera Dirah: Lontar Mpu Bharada
Genre Utama 2D Top-Down Stealth Exploration & Cultural Collector
Unsur Budaya Lokal Cerita Rakyat Calonarang (Kisah Mpu Bharada & Mpu Bahula), Filosofi Rwa Bhineda, Artefak Naskah Lontar Bali, dan Instrumen Gamelan Gender Wayang
Game Engine & Pipeline Unity 2D (Universal Render Pipeline / URP 2D Lights) dengan bahasa pemrograman C#
Target Platform PC Executable Build (Windows .exe / macOS .app) — Siap diekspansi ke Android (.apk) pada Proyek Akhir (UAS)
Perspektif Kamera Top-Down 2D Orthographic (Smooth Camera Follow pada Karakter Pemain)
Target Audiens Remaja hingga Dewasa (13+ tahun), pelajar/mahasiswa, dan pecinta game indie bertema budaya Nusantara

1.2 High Concept dan Ringkasan Premis

High Concept: Jelajahi kegelapan malam Desa Girah sebagai Bahula (murid Mpu Bharada), kelola energi cahaya Lentera Suci untuk menenangkan roh Bayangan Wabah, dan kumpulkan 3 naskah Lontar kuno ke Altar Penyucian untuk mengembalikan keseimbangan Rwa Bhineda.

Ringkasan Premis: Kabut wabah dari Setra Gandamayu telah menyelimuti Desa Girah. Mpu Bharada mengutus muridnya, Bahula, masuk ke jantung desa dengan berbekal sebuah Lentera Suci. Berbeda dari game aksi konvensional, pemain tidak menggunakan kekerasan fisik, melainkan mengandalkan manajemen cahaya lentera untuk membuka jarak pandang di tengah kegelapan dan melepaskan gelombang cahaya suci (Holy Light Burst) guna meredam Bayangan Wabah sembari mencari 3 Lontar Kuno (Lontar Usada, Lontar Dharma, dan Lontar Rwa Bhineda).

BAB II
ANALISIS DESAIN SISTEM (CORE LOOP & MDA FRAMEWORK)

2.1 Core Loop (Siklus Inti Permainan)

Berdasarkan prinsip Systems Analysis & Design untuk permainan digital, siklus aksi berulang (Core Loop) yang menjadi jantung gameplay “Lentera Dirah” terdiri atas 4 tahapan yang saling terhubung:

Bagan 2.1: Siklus Inti Permainan (Core Loop) “Lentera Dirah: Lontar Mpu Bharada”
1. EXPLORE
Menjelajahi lorong gelap Desa Girah dengan mengandalkan radius cahaya lentera yang menyusut perlahan. 		→ 2. EVADE & STUN
Menghindari patroli Bayangan Wabah atau menekan SPACE untuk membekukan (Stun) musuh selama 3 detik. 		→ 3. COLLECT
Mengambil Minyak Obor untuk isi ulang cahaya serta mengumpulkan 3 Lontar Suci. 		→ 4. PURIFY
Membawa 3 Lontar yang terkumpul menuju Altar Penyucian di tengah desa untuk menang.

2.2 Analisis Mechanics-Dynamics-Aesthetics (MDA) Framework

Komponen MDA Jabaran Spesifikasi Sistem dalam Permainan
Mechanics
(Aturan & Komponen Dasar Kode)		 1. Pergerakan karakter 4 arah berbasis komponen fisika Rigidbody2D (kecepatan = 4.5 unit/detik).
2. Penyusutan energi lentera (Light Decay) sebesar 2% per detik yang memperkecil radius Light 2D.
3. Mekanik Holy Light Burst (tombol Space) dengan biaya energi lentera 15%, cooldown 4 detik, dan radius deteksi Physics2D.OverlapCircle sebesar 3.5 unit.
4. Syarat buka segel Altar Penyucian: variabel lontarCollected == 3.
Dynamics
(Perilaku Interaksi Saat Bermain)		 1. Dilema Manajemen Sumber Daya Cahaya: Pemain harus menimbang kapan harus menghemat energi lentera agar pandangan tetap luas, dan kapan harus mengorbankan 15% energi lentera untuk melakukan Stun saat terkepung musuh.
2. Navigasi Taktis (Risk vs. Reward): Mengambil Lontar di sudut sempit menuntut pemain mengamati pola gerak Patrol NPC Bayangan terlebih dahulu.
Aesthetics
(Emosi yang Dirasakan Pemain)		 1. Tension & Relief (Ketegangan & Kelegaan): Atmosfer tegang saat menyusuri kegelapan malam diiringi gamelan Bali, diikuti rasa lega saat menemukan pancaran cahaya Lontar Suci.
2. Cultural Immersion (Penghayatan Budaya): Pengalaman menyelami filosofi Rwa Bhineda secara langsung melalui kontras cahaya dan bayangan.

BAB III
SPESIFIKASI MEKANIK GAMEPLAY & KONTROL DASAR

3.1 Skema Kontrol Dasar (Input & Movement)

Aksi Pemain Input Keyboard / Mouse Implementasi Teknis di Unity 2D
Bergerak 4 Arah (Atas, Bawah, Kiri, Kanan) Tombol W, A, S, D atau Arrow Keys Membaca Input.GetAxisRaw("Horizontal") dan Input.GetAxisRaw("Vertical"), dinormalisasi dengan vector.normalized agar gerak diagonal konsisten, lalu diterapkan pada Rigidbody2D.linearVelocity di dalam FixedUpdate().
Pancaran Cahaya Suci (Holy Light Burst) Tombol Spacebar Mengecek Input.GetKeyDown(KeyCode.Space). Jika lanternEnergy >= 15f dan cooldownTimer <= 0f, memicu kilatan cahaya dan mengubah state seluruh objek ber-tag/layer Enemy dalam radius 3.5f menjadi Stunned.
Interaksi UI / Lanjut Dialog / Restart Klik Kiri Mouse / Tombol E Event Button.onClick pada Canvas UI untuk mengubah state pada GameManager (dari MainMenu ke IntroDialog, lalu ke Playing).

3.2 Matriks Sistem Collision (Deteksi Tabrakan)

Objek A Objek B Tipe Collider 2D Respon Sistem & Efek Gameplay
Pemain / NPC Pohon Bambu, Pagar Batu, Bangunan Desa Solid Collision
(Is Trigger = false)		 Menahan pergerakan fisik objek menggunakan BoxCollider2D dan Tilemap​Collider2D agar tidak menembus batas lingkungan desa.
Pemain (Bahula) Item LontarSuci Trigger Collision
(Is Trigger = true)		 Menambah lontarCount (+1), menampilkan pesan edukasi lontar di HUD, memutar SFX genta (sfx_pickup_lontar), dan memanggil Destroy(gameObject).
Pemain (Bahula) Item MinyakObor Trigger Collision
(Is Trigger = true)		 Menambah energi lentera sebesar +35% (maksimal 100%), memperluas radius Light 2D, dan memutar SFX api obor.
Pemain (Bahula) NPC EnemyBayangan Trigger / Solid Jika state musuh bukan Stunned, mengurangi nyawa pemain (health - 1), mengaktifkan state Hurt (kebal sementara 1 detik), dan memutar sfx_hurt.
Pemain (Bahula) Objek AltarPenyucian Trigger Collision
(Is Trigger = true)		 Mengecek apakah lontarCount == 3. Jika terpenuhi, memutar sfx_victory dan mengubah Game State menjadi Victory.

3.3 Spesifikasi Dua Mekanik Gameplay Utama

  1. Mekanik Utama 1: Sacred Lontar Collection & Altar Seal System
    Pada awal permainan, Altar Penyucian yang terletak di pusat Desa Girah diselimuti segel kabut gelap. Pemain harus menjelajahi tiga sektor desa (Sektor Utara, Sektor Timur, dan Sektor Barat) untuk mengumpulkan 3 naskah Lontar Suci. Setiap Lontar yang diambil akan menyalakan indikator lontar pada HUD dan membuka kutipan kearifan lokal. Begitu ketiga Lontar terkumpul, segel Altar terbuka secara otomatis dan memancarkan cahaya emas sebagai penanda titik penyelesaian misi.
  2. Mekanik Utama 2: Dynamic Lantern Light & Rwa Bhineda Stun Burst
    Karakter Bahula dilengkapi komponen Light 2D (Point Light) yang radius terangnya berbanding lurus dengan persentase energi lentera (pada energi 100% radius luar adalah 6.0 unit; menyusut perlahan hingga minimal 1.8 unit). Apabila energi lentera mencapai 0%, kegelapan menyelimuti pemain sepenuhnya dan memicu kondisi kalah (Game Over). Pemain dapat menekan tombol Space untuk melepaskan pancaran cahaya suci yang membekukan (Stun) seluruh NPC Bayangan Wabah di sekitarnya selama 3 detik.

BAB IV
ARSITEKTUR STATE MANAGEMENT (FINITE STATE MACHINE)

4.1 Bagan Alur Finite State Machine (FSM)

Untuk menjamin struktur kode yang bersih, bebas bug, dan memenuhi indikator penilaian tertinggi pada kriteria State Management, permainan ini mengimplementasikan pola Finite State Machine (FSM) berbasis enum pada 3 tingkatan:

Bagan 4.1: Arsitektur Tiga Tingkat Finite State Machine (Game State, Player State, & Enemy AI State)
1. GAME STATE FSM
MainMenu → IntroDialog → Playing → (Victory / GameOver) 		2. PLAYER STATE FSM
Idle ↔ Walking → CastingLight / Hurt 		3. ENEMY NPC AI FSM
Patrol ↔ Chase → Stunned (3 Detik)

4.2 Tabel Spesifikasi State (Game, Player, & Enemy NPC AI)

Entitas Sistem Nama State (enum) Kondisi Pemicu Transisi (Trigger) Perilaku Sistem pada State Tersebut
Game Manager
(GameManager.cs)		 MainMenu Kondisi awal saat scene dimuat. Menampilkan panel judul utama; input karakter dinonaktifkan.
IntroDialog Pemain menekan tombol “Mulai Penyucian”. Menampilkan dialog instruksi Mpu Bharada kepada Bahula.
Playing Pemain menutup dialog pembuka. Mengaktifkan kontrol pemain, AI patroli musuh, dan pengurangan energi lentera.
Victory lontarCount == 3 dan pemain menyentuh Altar. Menghentikan musuh, memutar audio kemenangan, dan menampilkan layar Desa Girah Pulih.
GameOver playerHealth <= 0 atau lanternEnergy <= 0. Menampilkan layar gagal beserta tombol Coba Lagi (reload scene).
Karakter Pemain
(PlayerController.cs)		 Idle Vektor input gerakan bernilai (0, 0). Kecepatan Rigidbody2D diset ke nol; memainkan animasi Idle sesuai arah hadap.
Walking Pemain menekan tombol arah WASD / Panah. Menggerakkan karakter dan memainkan animasi langkah kaki 4 arah.
CastingLight Pemain menekan tombol Spacebar. Meningkatkan intensitas & radius Light 2D sesaat (0.3 detik) dan memicu efek Stun ke musuh.
Hurt Bersentuhan dengan NPC Bayangan aktif. Sprite karakter berkedip merah dan kebal sementara (invulnerability) selama 1 detik.
AI Musuh (NPC)
(EnemyShadowAI.cs)		 Patrol Jarak ke pemain > 4.0 unit. NPC bergerak otomatis menyusuri titik waypoints[] dengan kecepatan normal (2.2 unit/detik).
Chase Jarak ke pemain <= 4.0 unit. NPC mengejar posisi pemain dengan kecepatan 3.4 unit/detik; kembali ke Patrol jika jarak > 5.5 unit.
Stunned Terkena gelombang Holy Light Burst pemain. NPC berhenti bergerak selama 3.0 detik, warna sprite berubah biru pucat transparan, dan tidak melukai pemain.

BAB V
INTEGRASI BUDAYA (VISUAL, PRINSIP ANIMASI, AUDIO, & NARASI)

5.1 Arah Visual (Art Direction) dan Palet Warna Rwa Bhineda

Gaya visual menggunakan pendekatan 2D Top-Down Pixel Art yang dipadukan dengan pencahayaan atmosferik Unity URP 2D Lighting. Palet warna dirancang untuk memvisualisasikan dualisme Rwa Bhineda (kontras antara kegelapan kabut wabah dan hangatnya cahaya penyucian):

Sampel Nama Warna Kode Hex Fungsi Visual & Makna Simbolik Budaya
  Dirah Midnight #121324 Warna dasar atmosfer malam Desa Girah dan area Fog of War di luar jangkauan lentera.
  Sacred Lantern Gold #FFB84D Warna pancaran cahaya Lentera Suci, kilau item Lontar, dan aksen utama antarmuka pengguna (UI).
  Gering Shadow Violet #6B2D5C Warna aura NPC Bayangan Wabah saat berada pada state Patrol dan Chase.
  Purified Stun Cyan #64C8FF Warna umpan balik visual ketika Bayangan Wabah berhasil dibekukan (state Stunned).

5.2 Penerapan Prinsip Animasi Dasar (Basic Animation Principles)

  1. Pose-to-Pose & Walk Cycle Timing: Karakter Bahula dan NPC Bayangan memiliki siklus animasi jalan 4 arah (Atas, Bawah, Kiri, Kanan) menggunakan Animator Controller dan Blend Tree di Unity.
  2. Squash, Stretch, & Sinusoidal Floating (Gerak Mengambang Halus): Objek LontarSuci dan MinyakObor bergerak mengambang naik-turun secara berirama menggunakan fungsi trigonometri Mathf.Sin(Time.time * frequency) * amplitude sehingga terlihat hidup dan menarik perhatian pemain.
  3. Anticipation & Visual Feedback (Umpan Balik Cahaya): Saat pemain menekan Space (Holy Light Burst), radius cahaya membesar secara cepat lalu kembali ke ukuran semula, disertai perubahan warna musuh yang terkena efek Stun.

BAB VI
DESAIN UI/UX, USER FLOW, DAN WIREFRAME

6.1 Prinsip Desain UI/UX (Clarity & Consistency)

Sesuai teori perancangan antarmuka permainan digital (Stone dkk., 2005; Lee & Novak, 2022), desain UI/UX pada prototipe ini mengedepankan dua prinsip utama:

  • Klaritas / Kejelasan (Clarity): Mengingat latar permainan bernuansa malam gelap, seluruh indikator vital pada Heads-Up Display (Nyawa, Bar Energi Lentera, dan Jumlah Lontar) menggunakan warna emas menyala (#FFB84D) di atas panel gelap agar terbaca secara instan tanpa menghalangi pandangan pemain.
  • Konsistensi (Consistency): Seluruh komponen panel menu, kotak dialog Mpu Bharada, hingga layar kemenangan menggunakan tipografi, skema bingkai kayu-emas, dan gaya ikon piksel yang seragam.

7.5 Pencahayaan Dinamis (Unity URP 2D Lights)

  1. Global Light 2D (atmosfer malam wabah Girah): komponen Light 2D (Type: Global) dengan warna #121324 (Dirah Midnight) dan Intensity = 0.08 sehingga peta desa tampak gelap di luar jangkauan lentera.
  2. Point Light 2D (Lentera Suci Bahula): dipasang sebagai child object pada karakter pemain dengan warna hangat #FFB84D (Sacred Lantern Gold), Intensity = 1.4, dan Outer Radius dinamis antara 6.0 unit (energi 100%) hingga 1.8 unit.

BAB VIII
STRUKTUR PROJECT UNITY & PETA JALAN PENGEMBANGAN UAS

8.1 Organisasi Struktur Folder Project di Unity

Untuk memenuhi indikator penilaian kualitas struktur proyek dan kerapian source code, direktori proyek Unity diorganisasikan secara modular sebagai berikut:

  • Assets/_Project/Scripts/Managers/ — Berisi GameManager.cs dan AudioManager.cs.
  • Assets/_Project/Scripts/Player/ — Berisi PlayerController.cs (Input, Movement, Lantern Light Decay, & Stun Burst).
  • Assets/_Project/Scripts/Enemies/ — Berisi EnemyShadowAI.cs (FSM Patrol, Chase, & Stunned).
  • Assets/_Project/Scripts/Interactables/ — Berisi CollectibleItem.cs (Lontar & Minyak Obor) dan AltarPurification.cs.
  • Assets/_Project/Art/, Assets/_Project/Audio/, dan Assets/_Project/Scenes/ — Menyimpan sprite, tilemap, audio, dan scene utama.

8.2 Peta Jalan Ekspansi Menuju Proyek Akhir (UAS)

Prototipe Tugas 1 ini dirancang agar dapat langsung dikembangkan menjadi Proyek Akhir (UAS) tanpa membangun ulang dari awal, melalui tahapan ekspansi berikut:

  1. Penambahan 3 Level Berbeda dengan Progressive Difficulty Curve: Level 1 (Desa Girah Bagian Luar — Prototipe Tugas 1), Level 2 (Hutan Bambu Lemah Tulis), dan Level 3 (Pelataran Setra Gandamayu).
  2. Implementasi Fitur Wajib UAS: Penambahan sistem penyimpanan progres (Save System berbasis JSON/PlayerPrefs), menu pengaturan (Settings Menu untuk volume BGM/SFX), serta layar kredit (Credit Screen).
  3. Ekspor Lintas Platform: Menambahkan opsi kontrol Virtual Joystick pada Canvas UI untuk mendukung build PC (Windows/macOS) sekaligus Mobile (Android .apk).
